| Parcours | Modules associés |
|---|---|
| Cloud Foundations | Module 1 — Présentation des concepts du cloud ; Module 2 — Coûts du cloud et facturation ; Module 3 — Présentation de l'infrastructure mondiale AWS |
| Cloud Architecting | Module 1 — Bienvenue dans le cours ; Module 2 — Présentation de la conception d'architectures cloud |

<details><summary><strong>Parcours guidé</strong></summary>

1. Relever les cinq caractéristiques du cloud décrites dans le Module 1.
2. Distinguer estimation, budget et observation des dépenses dans le Module 2.
3. Représenter une région, plusieurs AZ et un point de présence après le Module 3.
4. Associer une décision d'architecture à chacun des six piliers Well-Architected dans le Module 2 de Cloud Architecting.
5. Terminer les contrôles de connaissances proposés dans le module.

**Validation observable :** expliquer pourquoi une architecture multi-AZ n'est pas automatiquement multi-région et citer une responsabilité AWS ainsi qu'une responsabilité client.
</details>
